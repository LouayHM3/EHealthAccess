# Responsible use

This repository uses synthetic demo data only. Never place real patient records, private keys, wallet mnemonics, JWT secrets, or production RPC credentials in the repository.

The demo policy engine is not a certified medical-record access-control system. A production implementation requires a formal privacy review, threat modeling, authenticated identities, secure key management, consent lifecycle controls, tamper-evident audit operations, legal review, and independent smart-contract auditing.
